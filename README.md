**Sunshine App**

A Progressive Web App (PWA) that helps users with their mental well-being. Users can practise daily gratitude, check in their mood for the day and get help with their sleep quality.

**Features**
- Practice daily gratitude by entering what you're thankful for
- Track gratitude entries by date, check past history as well
- Mood color themes that reflect your current emotional state 
- Data persistence using Ionic Storage
- Quotes API for daily motivation in the HomePage
- Sleep-helper page with plugin browser links to videos helping with sleep
- Users get greeted with their entered username
- Routing between multiple pages (Home, Gratitude, History, Settings, etc.)
